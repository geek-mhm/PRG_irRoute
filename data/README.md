The bundled seed is sourced from the `ipverse/geo-ip-blocks` Iran IPv4 dataset:

`https://raw.githubusercontent.com/ipverse/geo-ip-blocks/master/country/ir/ir-ipv4.txt`

Source project: `https://github.com/ipverse/geo-ip-blocks`

- Prefix count: 1,938
- Source file SHA-256: `2c7a22a0fc564ab1b72ca01c148bec30c682444e547b0a9c64dfc644a335834e`

This is an installation seed, not a guarantee of physical traffic origin. IP geolocation changes and can contain errors. Operators should review critical destinations and use force-route overrides where needed.

The offline installer imports this file only when no irroute data file already exists. It does not overwrite an existing server's active data during an application reinstall.
